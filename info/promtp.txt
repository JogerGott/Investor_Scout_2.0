# PROMPT – Sistema de Sincronización de Yahoo Finance para Portfolio Analyzer

## Contexto

Estoy desarrollando un sistema profesional de análisis y gestión de portafolios de inversión.

La base de datos MySQL ya se encuentra completamente diseñada y normalizada. El sistema debe consumir datos de Yahoo Finance, transformarlos al modelo de datos interno, calcular las métricas que Yahoo Finance no proporciona y almacenar toda la información preservando el histórico.

El objetivo es construir un **módulo ETL (Extract → Transform → Load)** robusto, desacoplado y escalable.

El código debe seguir principios SOLID, Clean Architecture y separación de responsabilidades.

No deseo un script monolítico.

Debe implementarse una arquitectura orientada a servicios.

---

# OBJETIVO

Diseñar e implementar un sistema capaz de:

1. Consultar Yahoo Finance.
2. Obtener toda la información disponible para un activo.
3. Transformar los datos al modelo interno.
4. Calcular las métricas financieras que Yahoo no provee.
5. Insertar o actualizar correctamente la base de datos.
6. Mantener el histórico de información.
7. Evitar duplicados.
8. Permitir futuras fuentes de datos distintas de Yahoo Finance.

---

# REQUISITOS DE ARQUITECTURA

La solución debe estar dividida en módulos independientes.

Ejemplo:

```
YahooFinanceService
        │
        ▼
FinancialMapper
        │
        ▼
FinancialCalculator
        │
        ▼
Repositories
        │
        ▼
MySQL
```

Cada módulo debe tener una única responsabilidad.
